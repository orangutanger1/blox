# Third-party code in this project

- **Game framework** (Lifecycle, Packet, services/controllers): based on
  [frrazer/roblox-game-boilerplate](https://github.com/frrazer/roblox-game-boilerplate),
  used with the author's permission.
- **Packet** networking library: see
  https://devforum.roblox.com/t/packet-networking-library/3573907.
- **Wally packages** (`ReplicatedStorage/Packages`, `ServerScriptService/ServerPackages`):
  sleitnick's Component, Input, Signal, TableUtil, Trove, WaitFor, Symbol;
  evaera's Promise; loleris's ProfileStore. Each keeps its own licence (LICENSE files
  inside `_Index` where the package ships one).
- **Replica** by MadStudio (loleris): Apache-2.0, `licenses/Replica-LICENSE`.
