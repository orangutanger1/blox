# Map component (`BloxMap` kit, `map check`, `map shots`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Maps get a kit of building blocks with a saturated default palette and a bright lighting preset, a `map check` that measures walkability with the real jump numbers plus build faults and a measured triangle budget, and `map shots` that returns one contact sheet of standard views.

**Architecture:** `map check` runs one edit-context Luau program (a port of the bake-off judge's `map_metrics.luau` with A's MapCheck ideas) that returns raw JSON; pure TS (`src/map/evaluate.ts`) turns it into `map:<id>` results with thresholds, written to `.blox/map-report.json`. Triangles come from `SceneAnalysisService:GetTriangleCompositionAsync()` (works in edit, measures the current camera frame), taken at the play-height spawn view and the top-down view with the edit camera set Scriptable and restored. `map shots` frames cameras on the reachable bbox from the last check (else the map bbox), captures them with `screen_capture`, and joins them with `composeSheet`; the sheet's mean pixel saturation is reported. The kit is Luau under `kits/_common/files/src/ReplicatedStorage/BloxMap`, installed by `map install`, tested offline with Lune.

**Tech Stack:** TypeScript, Luau, Lune specs, jpeg-js.

**Spec:** `docs/superpowers/specs/2026-10-07-ui-map-refine-design.md` §5 (finding: the judge's 226k triangles for B were 132k shadow pass + 93k opaque; A rendered no shadow pass)

## Global Constraints

- Config `blox.config.json` `map`: `{ root = "Workspace.Map", spawns = { <group>: <path> }, jumpHeight?, walkSpeed?, boundary? {min:[x,z], max:[x,z]}, interiorTag = "Interior", triangleBudget = 60000 }`.
- Jump used = config `jumpHeight` if set, else from StarterPlayer (CharacterJumpHeight, or JumpPower²/(2·gravity) when CharacterUseJumpPower) **+ 0.9 studs take-off** (measured: JumpPower 50 → 7.27, 53.15 → 8.2).
- Result ids: `map:spawns-reach`, `map:pockets`, `map:roofs`, `map:covered`, `map:floating`, `map:overlap`, `map:leak`, `map:triangles`, `map:saturation`. Errors: spawns-reach, pockets, leak, triangles. Warnings (ok=true with detail): roofs, covered, floating, overlap, saturation.
- Edit mode only; the camera is always restored; staged probes always destroyed.

## Review Focus

- No map root → clear error naming the configured path.
- No SpawnLocation under the root → error "add a SpawnLocation" (no BFS start), not 0/0 passes.
- A spawn group path that doesn't exist → listed as missing, `spawns-reach` fails.
- SceneAnalysisService unavailable → triangles reported "not measured" (ok, note) rather than crash.
- Huge maps (> 60k grid columns) → step grows to keep the grid under the cap, and the report says the step used.
